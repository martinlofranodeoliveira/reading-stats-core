# reading-stats-core

Estatísticas de leitura: palavras, caracteres, frases, parágrafos,
tempo de leitura/fala. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 3 testes, node:test, sem dependências
npm run demo
```

Taxas fixas 200/130 ppm; no máximo 1M caracteres. MIT — veja `LICENSE`.
